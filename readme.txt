물건을 살 수 있는지 파악하고 주소를 찾는 등 다양한 쿼리 유형을 수행하는 프로그램입니다.

## 특징
- MySQL 데이터베이스에 연결하여 데이터를 저장하고 검색합니다.
- 다양한 쿼리 유형:
  - 지구별, 학군별 등 다양한 기준에 따라 물건을 찾습니다.
  - 총 판매액에 따라 상위 에이전트를 찾는 등 판매 데이터를 분석합니다.
  - 특정 연도에 판매된 물건의 평균 판매 가격 및 평균 시장에 머무른 시간을 계산합니다.
  - 부동산 판매 기록을 저장하고 데이터베이스에 새로운 에이전트를 추가합니다.

## 필요 사항
- MySQL 데이터베이스 설치 및 실행.
- MySQL C API (libmysql) 설치.
- C 컴파일러(GCC 등) 설치.

## 사용 방법
1. MySQL 서버가 실행 중인지 확인합니다.
2. C 컴파일러를 사용하여 프로그램을 컴파일합니다. 예시:
    ```bash
    gcc -o real_estate_management real_estate_management.c -lmysqlclient
    ```
3. 컴파일된 프로그램을 실행합니다:
    ```bash
    ./real_estate_management
    ```
4. 화면에 나오는 프롬프트에 따라 쿼리 유형을 선택하고 하위 유형을 선택하고 매개변수를 입력하고 결과를 확인합니다.

## 쿼리 유형
1. **물건을 살 수 있는지 확인**: 지구별에 따라 물건을 쿼리합니다.
2. **학군별로 물건 찾기**: 학군별로 물건을 쿼리합니다.
3. **총 판매액에 따라 상위 에이전트 찾기**: 총 판매액에 따라 상위 에이전트를 찾는 판매 데이터를 분석합니다.
4. **부동산 통계 계산**: 특정 연도에 판매된 물건의 평균 판매 가격 및 평균 시장에 머무른 시간을 계산합니다.
5. **비싼 물건의 사진 표시**: 다양한 유형의 가장 비싼 물건의 사진을 표시합니다.
6. **부동산 판매 기록**: 데이터베이스에 물건 판매를 기록합니다.
7. **새로운 에이전트 추가**: 데이터베이스에 새로운 에이전트를 추가합니다.
